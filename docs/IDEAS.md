# 機能アイデア集 — 文字PV × 画像・動画のその先

[PLAN.md](PLAN.md) の Phase 5 以降の候補。「何をやっている人か」（音楽制作／歌ってみた／VTuber／動画編集の受託／SNS 運用…）で優先度が大きく変わるので、
**★ = 画像・動画対応と相性がよく、実装も比較的軽いもの**に印を付けています。本家（852wa/JIZURA）に無く、他フォークにあるものは出典を書いています。

---

## A. 画像・動画そのものを活かす

| # | アイデア | 中身 | 手間 |
|---|---|---|---|
| A1 ★ | **拍に合わせた写真スライドショー** | `autoFill.perBeat`：拍（または 2 拍・小節）ごとに写真を切り替える。サビだけ倍速切替。曲の `energy` が高い区間ほど速く | 小（Phase 1 の autoFill の拡張） |
| A2 ★ | **写真をスタイルに馴染ませる（`treat:'match'`）** | スタイルの `bg`/`accent` の 2 色でデュオトーン化、粒子・紙テクスチャを上から共有。写真が「素材っぽく」ならない | 小〜中 |
| A3 ★ | **文字で写真を抜く（テキストマスク）** | 巨大な歌詞の形に写真／動画を切り抜く。逆に写真の形に文字を敷き詰める。レイアウト部品として `J.register('layout', 'photoKnockout', …)` | 中 |
| A4 | **写真の中に歌詞を置く（画像内レイアウト）** | 写真の余白（空・壁）を輝度分散で検出して、そこに歌詞を自動で置く。`fits` と `plan` で候補矩形を選ぶ | 中〜大 |
| A5 ★ | **Ken Burns の自動化** | 写真ごとに「寄る／引く／横に流す」を拍長に合わせて自動で決める。行の感情（emph）が強いほど大きく | 小 |
| A6 | **画像連番・GIF・APNG** | フレームアニメを素材として読む（GIF は `ImageDecoder`、連番は ZIP ドロップ） | 中 |
| A7 | **クロマキー動画の前景合成（立ち絵・VTuber）** | Phase 3 で実装。加えて「口パク検出でその区間だけ字を大きく」など | Phase 3 |
| A8 | **メディア専用の装飾** | 写真の四隅にフィルムの縁、ポラロイド枠、テープ、写真番号 HUD。`decor` 部品として追加（本家の装飾 115 と同じ登録方式） | 小〜中 |
| A9 | **動画の音を曲にする** | MV 撮影素材の同録音声から拍を取る。Phase 2-6 | Phase 2 |
| A10 | **背景のぼかし・鏡面で縦動画化** | 16:9 の写真を 9:16 で使うとき、上下を同じ写真のぼかし拡大で埋める（TikTok 定番） | 小 |

## B. 制作ワークフロー（作る速さ）

| # | アイデア | 中身 | 手間 |
|---|---|---|---|
| B1 ★ | **1 プロジェクトから複数の画面比を一括書き出し** | 16:9 / 9:16 / 1:1 を一度に MP4 で。レイアウトは `portrait` 重みで自動で変わる。素材の `rect` は比率ごとに持てるようにする | 小〜中 |
| B2 ★ | **自分のプリセット（「マイスタイル」）** | スタイル＋配色＋フォント＋演出スライダー＋メディア設定を名前付きで保存・呼び出し。`J.STYLES` に追加登録 or `project` の部分保存 | 小 |
| B3 | **手法のお気に入り・履歴** | 気に入ったカットの部品の組み合わせを☆で保存し、「この行にお気に入りを適用」。hirazisora フォークに `11u_effect_favorites.js` がある | 中 |
| B4 ★ | **単語単位のタイミング（カラオケ／歌詞ハイライト）** | 行内の語の開始時刻を持ち、キネティック部品が語の切替を拍でなく実時刻に合わせる。入力は「タップ同期」の語モード、または B5 の取り込み | 中 |
| B5 ★ | **字幕・書き起こしの取り込み** | SRT / ASS / TTML / Whisper の JSON（word timestamps）を読む。LRC 読み込み（本家 v0.10）を拡張するだけ。書き出しは SRT/ASS も | 小 |
| B6 | **セクション（Aメロ/Bメロ/サビ）ごとの設定** | 歌詞に `[サビ]` などのマーカーを書くと、セクションごとにスタイル・雰囲気・メディアの autoFill を変えられる。本家の `unify`（繰り返しを同じ見せ方）と相性がよい | 中 |
| B7 | **プロジェクトの履歴・スナップショット** | 「前の案／次の案」を名前付きで固定し、後から戻れる。IndexedDB に保存 | 小 |
| B8 | **バッチ処理（CLI）** | Playwright で headless に `project.json` → MP4。曲を差し替えて量産、Claude から呼べる。hirazisora の `mcp/` がほぼこれ | 中 |
| B9 | **MCP サーバー（エージェントから制作）** | 「この歌詞と曲と写真で、しっとり系で 9:16、サビは写真を速く切り替えて」を Claude に頼むと書き出しまで行う。hirazisora の `mcp/server.mjs` を移植可能（MIT） | 中 |

## おすすめの順番（画像・動画対応が終わったあと）

1. **A1 拍スライドショー + A5 Ken Burns + A2 スタイル馴染ませ** — 写真を置いただけで「それっぽい MV」になる。実装は Phase 1〜3 の延長。
2. **B1 複数画面比の一括書き出し + C1 セーフエリア + C2 ティザー切り出し** — SNS 展開が一気に楽になる。
3. **B5 字幕取り込み + B4 語タイミング** — Whisper 等で文字起こし → 語単位で光る歌詞。歌ってみた・カバー動画で差が出る。
4. **B9 MCP サーバー** — Claude に「この素材で作って」と頼める。hirazisora の実装が MIT で移植できる。

**確認したいこと**：あなたの主な用途はどれに近いですか？（自作曲の MV／歌ってみた／VTuber・配信のテロップ／受託の動画編集／SNS 用ショート）— これで A〜F のどこを厚くするか決めます。
